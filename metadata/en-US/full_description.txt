An open-source SMS app for Android, based on QKSMS.
## Features
- Scheduled Messages
- Message Backup
- Speech to Text and Text to Speech integrated within the app
- Message Blocking and Archiving
- Voice Messages
- Attachments of any type of file
- Message Sorting
- Delayed Sending

Find the project at <a href="https://github.com/victor-root/openmessages">github.com/victor-root/openmessages</a>
